# DAF-seq

Single-molecule accessibility and transcription-factor footprints at the IDO1, CXCL11 and STAT1
promoter amplicons. `processing/` has to run first; after that `python accessibility/run_all.py`
runs the three numbered stages and draws Fig 4A-C, and `python tf_footprints/run_all.py` draws
Fig S8A-D. `data/` holds the locus registry and the CXCL11 50 bp scout density table that
Fig S8C is drawn from.
